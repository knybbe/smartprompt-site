Install (Chrome / Edge desktop)

  1. Download Full or Lite and unzip the archive.
  2. Open chrome://extensions or edge://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked and select the unzipped folder (the one that contains manifest.json).
  5. Open Options from the extension card, pick a provider, then use ✨ or the hotkey on a supported chat site.

Mobile (Android)

Chrome on Android

Not supported. Chrome for Android does not install browser extensions (no Load unpacked, no store sideload for MV3 packages like SmartPrompt). Use desktop Chrome/Edge, or Edge on Android below.

Edge on Android

Stable Edge only installs extensions from Microsoft’s curated Android list — SmartPrompt is not in that list, and you cannot “Load unpacked” from a zip the way you do on desktop.

Best-effort (Edge Canary): some builds let you install a .crx via Developer options.

  1. Install Microsoft Edge Canary from Play Store.
  2. Open edge://flags, enable anything labeled like Android Extension if present, then restart.
  3. Settings → About Microsoft Edge → tap the build number ~5 times until Developer options unlock.
  4. Developer options → Extension install by crx (name may vary) → pick the SmartPrompt .crx from Downloads (prefer Lite on phones; use BYOK in Options).
  5. Open ChatGPT/Claude/etc. and use the in-page ✨ button (hotkeys are unreliable on mobile).

“Install by ID” only works for extensions already on the Edge Add-ons store — not for these GitHub zips.

Expect rough edges: Nano/WebGPU/Gemma often missing on phones; BYOK is the reliable provider. iOS is deferred.
